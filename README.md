# AlwaysFirst

Starter static landing page for AlwaysFirst — a privacy-first directory to share and discover great sites.

What I added:

- index.html — SEO-friendly static homepage with share & copy UX
- robots.txt — allow indexing
- sitemap.xml — points to `/`
- README.md — instructions to deploy and next steps

Quick deploy options:

1. GitHub Pages (free):
   - Settings → Pages → Source: `main` branch → `/ (root)` → Save
   - Add your custom domain in Pages settings if you have one
   - Submit the site to Google Search Console (enter your domain or the GitHub Pages URL)

2. Vercel / Netlify (recommended for faster builds and future features):
   - Connect your GitHub repo and deploy
